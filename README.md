# Temu 全托管采购订单分析

Python + Streamlit + pandas + Plotly 的中文采购订单分析工具。

**采购订单不等于消费者订单，采购件数不等于消费者实际销量，采购金额不等于真实销售额、回款或利润。** 本项目不接入消费者成交数据，也不推算这些指标。

## Windows 下载后双击运行（无需输入命令）

1. 在 GitHub 仓库选择包含程序的分支，点击绿色 **Code → Download ZIP**。
2. 下载后右键 ZIP，选择“全部解压”，不要在压缩包内直接运行。
3. 从 [Python 官网](https://www.python.org/downloads/release/python-31210/) 安装 Python 3.12，勾选 **Add Python to PATH** 并保留 Python Launcher。
4. 打开解压后的文件夹，双击 **启动系统.bat**。首次需联网安装依赖，请等待；使用时保留这个窗口。
5. 浏览器通常自动打开；未打开时在地址栏输入 `localhost:8501`。
6. 在左侧选择“上传报表”，上传仓库内 **模拟采购订单.xlsx** 验证；之后再选择自己的文件。模拟 CSV 也包含在仓库中。
7. 在“明细与导出”下载分析 Excel。关闭启动窗口即停止服务。

Windows 启动器未经过 Windows 实机验证；Python 应用、模拟 Excel 上传、统计、图表和导出已在云端浏览器验证。Mac 可使用“启动系统.command”，详细提示见“先读我.txt”。

## 命令行启动

需要 Python 3.10 或更新版本，建议 Python 3.12。

```bash
cd /workspace/temu-sales-analytics  # 本机请替换为实际仓库目录
python -m venv .venv
.venv/bin/python -m pip install -r requirements-lock.txt
.venv/bin/python -m streamlit run app.py --server.address 0.0.0.0 --server.port 8501
```

仓库同时提供直接依赖 `requirements.txt` 和本次 Python 3.12 已验证的完整依赖锁定文件 `requirements-lock.txt`。

Windows：使用 `.venv\Scripts\python.exe` 替换上述 `.venv/bin/python`。在支持访问的本地环境用浏览器打开 Streamlit 提示的地址；云环境需使用平台支持的端口访问方式。

## 操作说明

1. 默认载入90天可重复生成的模拟采购数据，可下载 CSV 作为格式样例。模拟日期随当天变化。
2. 左侧选择“上传报表”，上传 `.xlsx`、`.xls` 或 `.csv`；Excel 可选工作表。CSV 支持 UTF-8/GB18030，第一行应为列名。请先去除标题行、合计行，合并单元格，并将 SKU/订单号保存为文本以保留前导零。
3. 检查自动匹配，手动修正必填日期、SKU、数量、供货价、状态。**供货价必须是每件单价，不是行金额**。同一原始列不可重复匹配。订单号、SPU、颜色、尺码为可选，不会从 SKU 猜测属性。
4. 设置纳入状态、日期和币种。默认排除名称包含取消/关闭/作废/cancel/closed的状态，请复核业务含义。订单号存在时按唯一订单号计数；没有时仅显示明细行数。若已匹配订单号但所选记录有空号，需修正或取消匹配。
5. 查看每日采购订单/明细数、件数和金额；趋势以筛选结束日为基准显示近7/30天。查看 SPU/SKU/颜色/尺码排行、环比和异常。
6. 在“明细与导出”下载 Excel，包含口径、每日汇总、增长、异常、有效明细、无效数据和4种排行。

## 计算口径与限制

- 数量必须为正整数；供货单价必须为非负有限数字。日期、SKU、状态缺失及无效数值会排除并附原因。零价记录允许；负数退货记录不纳入，第一版不支持退货冲减。
- 金额按每行数量×单价保留2位后求和；不换汇，不混合汇率，上传前请保证币种一致。单位输入仅为标签。
- 同一订单多行按明细汇总数量金额，订单数去重；每日按当日去重，同一订单若跨日期会分别计入各日，全局订单数可能不等于每日之和。
- 不自动去重采购明细，也不推断取消记录与原订单的关联。请提供单次完整且不重复的订单状态快照，避免合并多个重复导出文件。
- 所选观察范围缺失日期补零，仅表示报表无记录，不证明实际没有采购。最近一天可能未结束，缺报及状态筛选均影响分析。
- 环比以所选结束日回看7/30天，与上一等长周期比较；观察范围至少14/60天，上期为零时不计算百分比。
- 异常用此前7个自然日均值与总体标准差：偏差超过3倍标准差且至少5件时提示增长/下降，不代表业务结论或预测。
- 无效数据表包含整个源文件的无效行；有效明细及其他分析表按所选日期、状态筛选。字段映射及源数据行号便于复核。
- 上传数据不写入磁盘或第三方服务，仅在服务进程内处理；本工具没有账号、权限隔离或持久化，请仅部署在可信受控环境。默认上传限制200MB，较大文件会消耗更多内存。
