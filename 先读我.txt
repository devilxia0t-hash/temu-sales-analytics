Temu 采购订单分析系统（本机运行）

Windows 最简单运行步骤：
1. 从 https://www.python.org/downloads/ 安装 Python 3.12，安装时勾选 Add Python to PATH，并启用 Python Launcher（默认勾选）。
2. 将运行包完整解压到一个文件夹。不要直接在压缩包里运行。
3. 双击“启动系统.bat”，首次会联网安装依赖，请等待。允许时浏览器会自动打开。
4. 浏览器未自动打开时，在浏览器地址栏输入 localhost:8501。
5. 页面左侧选“上传报表”，选择包内“模拟采购订单.xlsx”，即可体验分析，再上传自己的文件。
6. 在“明细与导出”点“导出 Excel 分析结果”。
7. 使用期间保留启动窗口。关闭窗口即停止服务，重新双击可以再次启动。

Mac：安装 Python 3.12 后，双击“启动系统.command”。系统若提示权限或无法验证，请使用终端运行 README 中的步骤或联系维护人员；不要绕过公司安全策略。

本包不包含 Python 和依赖，首次安装需要网络。启动器已检查脚本内容，但未在 Windows/Mac 实机验证。
本工具没有账号系统，默认本机启动只供本机访问。
采购订单数/件数/金额不是消费者真实销量或销售额。
详细数据口径见 README.md。
